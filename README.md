# Cricket Captain 3D

An original cartoon 3D arcade cricket game built for iPhone Safari and desktop browsers.

## Current vertical slice

- Opening screen
- Three captain presets
- Four fictional teams
- Cartoon 3D stadium and characters
- One-over target chase
- Swipe batting controls
- Runs, wickets and match result
- Landscape iPhone support
- PWA shell and GitHub Pages deployment

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The deployment workflow publishes the `dist` folder from the `Test-Repository` branch.
